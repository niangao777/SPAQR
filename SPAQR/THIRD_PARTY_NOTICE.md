# Third-party source notice

The experiment runner, dataset wrappers, and parts of the utility code are
adapted from [PyOmniTS](https://github.com/Ladbaby/PyOmniTS). Source files that
originate there retain an explicit source comment.

The irregular-time-series dataset/task code under
`data/dependencies/tsdm/` is a minimal subset of
[tsdm](https://github.com/randolf-scholz/tsdm), retained for the four benchmark
pipelines used by SPAQR.

Before public redistribution, include the license texts required by the exact
upstream revisions used in the project, together with the license selected for
SPAQR itself.
